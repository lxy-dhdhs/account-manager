# 账号仓库管理系统

专为**幽境危战**直播打造的玩家排队与管理工具。三个独立仓库分级管理水友账号，一键顺排、OBS 绿幕报幕，让排队流程自动化。

## 功能

- **三级仓库** — 保时捷（最高优先级）、热气球（中等）、比心兔兔（常规），按优先级报幕
- **批量导入 / 手动添加** — 支持 TXT 批量导入并选择目标仓库；手动添加自动识别空格、逗号、分号、斜杠等分隔符
- **顺排队列** — 选中账号移入共享 FIFO 队列，先排先打，支持拖拽排序与「上移 / 下移」按钮调序
- **移出 / 清空队列** — 移出的账号返回原仓库原位置，也可一键清空整个顺排仓库
- **一键完成** — 「完成」删除仓库第一个账号；「顺排完成」删除队列第一个账号
- **OBS 绿幕报幕** — 绿色背景面板，OBS 添加色度键滤镜即可透明叠加到直播画面，显示当前 / 预备 / 顺排账号
- **预备账号顺延** — 预备账号不足时自动按优先级从其他仓库补位，报幕内容始终填满
- **撤销还原** — 每一步操作都可撤销（最多保留 50 步），快捷键 `Ctrl+Z`
- **操作日志** — 所有操作自动记录到 `operation_log.jsonl`，可在「查看日志」窗口倒序查看
- **表格导出** — 每次操作后自动导出账号表格 CSV 到 `account_tables/` 目录，按仓库分列

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+O` | 导入账号 |
| `Ctrl+B` | 显示 / 隐藏报幕面板 |
| `Ctrl+Z` | 撤销上一步操作 |
| `Delete` | 删除选中账号 |

## 快速上手

1. **导入账号** — 点击「导入账号」选择 TXT 文件，或「添加账号」手动输入
2. **开始排队** — 选中仓库中的账号，点击对应仓库的「顺排」按钮
3. **打开报幕** — 点击「报幕」显示底部绿色报幕面板
4. **OBS 设置** — 窗口捕获主程序 → 裁切绿色区域 → 添加色度键滤镜（绿色）
5. **打完完成** — 点击「完成」移除当前账号，下一个自动顶上
6. **顺排完成** — 点击「顺排完成」删除队列第一个账号

## 安装

下载 `dist/账号仓库管理系统_Setup.exe` 运行安装程序，或进入网页 <https://lxy-dhdhs.github.io/account-manager/> 下载安装程序。自动创建桌面快捷方式和开始菜单项，无需安装 Python 或其他运行环境，开箱即用。

支持 Windows 10/11。

## 开发

```bash
# 运行
python main.py

# 打包
pyinstaller 账号仓库管理系统.spec

# 生成安装程序（需要 NSIS）
makensis installer.nsi
```

- **Python 3.x** + tkinter
- **PyInstaller** 打包为 exe
- **NSIS** 生成安装包

## 数据结构

账号数据存储在 `account_data.json`：

```json
{
  "warehouses": {
    "porsche": ["玩家A", "玩家B"],
    "balloon": ["玩家C"],
    "bunny": ["玩家D", "玩家E"]
  },
  "queue": [
    ["porsche", "玩家A", 0]
  ]
}
```

- `warehouses`：三个仓库的账号列表，`porsche` / `balloon` / `bunny` 分别对应保时捷、热气球、比心兔兔仓库
- `queue`：顺排仓库，每个元素为 `[来源仓库 key, 账号名, 原仓库索引]`；原索引用于「移出队列」时还原账号在原仓库中的位置

## 数据文件

| 文件 | 说明 |
| --- | --- |
| `account_data.json` | 仓库与队列数据 |
| `operation_log.jsonl` | 操作日志（每行一条 JSON，追加写入） |
| `account_tables/` | 自动导出的账号表格 CSV（带导出时间戳） |
