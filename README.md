# 账号仓库管理系统

专为**幽境危战**直播打造的玩家排队与管理工具。三个独立仓库分级管理水友账号，一键顺排、OBS 绿幕报幕，让排队流程自动化。

## 功能

- **三级仓库** — 保时捷（最高优先级）、热气球（中等）、比心兔兔（常规），按优先级报幕
- **批量导入 / 手动添加** — 支持 TXT 导入，自动识别空格、逗号、分号等分隔符
- **顺排队列** — 选中账号移入共享 FIFO 队列，支持拖拽调序
- **OBS 绿幕报幕** — 绿色背景面板，OBS 添加色度键滤镜即可透明叠加到直播画面
- **预备账号顺延** — 当前仓库预备不足时自动从下一优先级仓库补位

## 快速上手

1. **导入账号** — 点击「导入账号」选择 TXT 文件，或「添加账号」手动输入
2. **开始排队** — 选中仓库中的账号，点击对应仓库的「顺排」按钮
3. **打开报幕** — 点击「报幕」显示底部绿色报幕面板
4. **OBS 设置** — 窗口捕获主程序 → 裁切绿色区域 → 添加色度键滤镜（绿色）
5. **打完完成** — 点击「完成」移除当前账号，下一个自动顶上
6. **顺排完成** — 点击「顺排完成」删除队列第一个账号

## 安装

下载 `dist/账号仓库管理系统_Setup.exe`或进入网页https://lxy-dhdhs.github.io/account-manager/下载安装程序，运行安装程序，自动创建桌面快捷方式和开始菜单项。无需安装 Python 或其他运行环境，开箱即用。

支持 Windows 10/11。
